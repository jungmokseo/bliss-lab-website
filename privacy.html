목적과 적용 범위

BLISS Lab의 기본 방문 통계는 웹사이트의 방문 규모와 유입 경로를 파악하기 위한 것입니다. 무료 Cloudflare Web Analytics 분석 코드가 설치된 메인 홈페이지와 공개 자료실 페이지에서는 방문 시 Cloudflare에 분석 요청이 전송됩니다.

전송되는 정보

Cloudflare의 공식 문서에 기재된 수집 항목은 다음과 같습니다.

  • 방문한 페이지의 URL과 이전 페이지의 referrer URL.
  • 페이지 로드 ID, 시각, 페이지·리소스의 성능 타이밍 및 Web Vitals 등의 성능 정보.
  • 브라우저, 운영체제와 엔진 버전 등의 기술 정보.

페이지 로드 ID는 개별 페이지 로드를 구분하는 값이며 지속적인 방문자 식별자와는 다릅니다. 이전 페이지 주소에는 경로가 포함될 수 있습니다. 수집 항목 설명

Cloudflare FAQ는 쿼리 문자열을 기록하지 않는다고 설명합니다. 이 설명이 전송되는 모든 URL·referrer·리소스 정보에서 쿼리 문자열이 사전에 제거됨을 보장하는 것은 아닙니다. URL 관련 FAQ

수신자는 Cloudflare입니다. 분석 코드는 static.cloudflareinsights.com에서 불러오고, 자료는 cloudflareinsights.com/cdn-cgi/rum으로 보냅니다. 수집 경로

쿠키·브라우저 저장과 IP 처리

Cloudflare는 이 분석 코드가 쿠키와 브라우저 저장소(localStorage, sessionStorage, IndexedDB)를 읽거나 쓰지 않는다고 설명합니다.

HTTP 통신 과정에서 Cloudflare가 IP 주소를 수신합니다. 공식 설명에 따르면 가까운 데이터센터에서 IP를 폐기하고 핵심 데이터베이스나 로그에 저장하지 않습니다. 라우팅에 따라 다른 나라에서 처리될 수 있으며, 정확한 저장 국가와 모든 사본·백업의 위치는 확인되지 않았습니다. 저장소·IP·처리 위치 설명

이 설명은 Cloudflare 분석 코드에 관한 것입니다. 기존 사이트의 Google Fonts, CDN, Google Maps 등 별도 리소스 요청은 이 분석 설치와 별개입니다.

조회 기간과 보관

공식 FAQ에 따르면 통계는 최근 6개월 범위를 조회할 수 있습니다. 샘플링하지 않은 전송 자료는 7일간 보관하며, 이후에는 약 10% 규모로 줄인 장기 자료를 사용합니다. 조회 자체에도 동적 샘플링이 적용될 수 있습니다.

6개월은 조회 가능한 기간입니다. 전체 자료·사본·백업의 정확한 삭제 기한은 확인되지 않았습니다. 보관·샘플링 FAQ

통계의 의미와 한계

페이지 조회수에는 반복 방문이 포함됩니다. Visits는 다른 사이트나 직접 링크로 시작한 방문 기준이며 고유한 사람 수가 아닙니다. 봇, 차단 기능, 여러 기기와 네트워크 실패로 실제 이용과 차이가 생길 수 있습니다. 국가 분류도 개인의 국적을 뜻하지 않습니다. 지표 정의

설치 전에 수집하지 않은 방문 기록은 복원할 수 없습니다. 유입 경로는 앱이나 브라우저 정책으로 누락될 수 있습니다. AI 유입은 클릭 시 출처가 전달된 경우에만 확인할 수 있고, 클릭 없는 AI 답변 속 언급은 관측할 수 없습니다. ‘직접/알 수 없음’은 AI 유입을 뜻하지 않습니다.

English notice

Purpose and scope

The purpose of BLISS Lab’s basic website statistics is to understand traffic volume and referral sources. On main-website and public research-library pages where the free Cloudflare Web Analytics code is installed, visiting a page sends analytics requests to Cloudflare.

Information transmitted

Cloudflare's official documentation describes the following collected fields.

  • The visited page URL and the referring page's URL.
  • A page-load ID, timing, page/resource performance timings and performance information such as Web Vitals.
  • Technical information including browser, operating-system and engine versions.

A page-load ID distinguishes individual page loads and is not a persistent visitor identifier. A referrer may contain a path. Collected fields

Cloudflare’s FAQ says query strings are not recorded. This does not establish that query strings are removed from every URL, referrer or resource field before transmission. URL FAQ

The recipient is Cloudflare. The analytics code loads from static.cloudflareinsights.com and sends data to cloudflareinsights.com/cdn-cgi/rum. Collection route

Cookies, browser storage and IP processing

Cloudflare states that its analytics code does not read or write cookies or browser storage (localStorage, sessionStorage or IndexedDB).

Cloudflare receives the IP address through the HTTP connection. It says the IP is discarded at a nearby data centre and not stored in its core database or logs. Routing may cause processing in another country. The exact storage countries and locations of all copies or backups have not been established. Storage, IP and processing-location description

This description concerns Cloudflare's analytics code. Existing Google Fonts, CDN, Google Maps and similar resource requests are separate from this analytics installation.

Reporting window and retention

The official FAQ describes access to the most recent six months of statistics. Unsampled received data is retained for seven days, after which a reduced long-term dataset of approximately 10% is used. Queries may also be dynamically sampled.

Six months is the reporting window. The exact complete-deletion deadline for all records, copies and backups has not been confirmed. Retention and sampling FAQ

Meaning and limits of the statistics

Page views include repeat visits. Visits start from another website or a direct link; they are not unique-person counts. Bots, blockers, multiple devices and network failures may cause differences from actual usage. A country classification does not establish a person's nationality. Metric definitions

Previously uncollected visits cannot be reconstructed. Apps and browser policies may remove referral information. AI referrals can be recognised only when a click carries a source; mentions in AI answers without clicks cannot be observed. “Direct/unknown” does not establish AI traffic.
